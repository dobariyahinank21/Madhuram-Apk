1. github.com par free account banaiye aur New repository banaiye.
2. Is folder ki saari files (".github" folder samet) repo mein upload kijiye.
3. Repo ke "Actions" tab mein "Build APK" chalne dijiye (3-5 minute).
4. Complete hone par us run ko kholiye, neeche "Artifacts" se MadhuramBusBooking-apk download kijiye.
5. Zip kholkar app-debug.apk phone mein install kijiye.

LOGO BADALNA: apna logo (512x512 ya 1024x1024 PNG) bhejiye, ya app/src/main/res/mipmap-* folders ke
ic_launcher.png aur ic_launcher_round.png ko usi naam se replace kijiye.
